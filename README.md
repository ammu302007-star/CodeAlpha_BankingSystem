# CodeAlpha Banking System

A menu-driven Banking System developed in C using structures, functions, and file handling.

## Features

- Create Account
- Prevent duplicate account numbers
- Deposit money
- Withdraw money
- Balance Enquiry
- View Account Details
- Search Account
- Input validation
- Prevent withdrawal beyond available balance
- Permanent account data storage
- Menu-driven interface
- Invalid input and menu choice handling

## Technologies Used

- C Programming
- Structures
- Functions
- File Handling
- Binary File Operations

## How to Run

### Compile

gcc banking_system.c -o banking_system

### Run

./banking_system

For Windows:

banking_system.exe

## Data Storage

Account records are stored permanently in a binary file named `accounts.dat`.

The file is created automatically when an account is created.

## Menu

1. Create Account
2. Deposit
3. Withdraw
4. Balance Enquiry
5. Account Details
6. Search Account
7. Exit

## Project Overview

This project implements a Banking System with the required operations of Deposit, Withdraw, Balance Enquiry, and Exit, using functions, structures, and file handling for permanent data storage.
